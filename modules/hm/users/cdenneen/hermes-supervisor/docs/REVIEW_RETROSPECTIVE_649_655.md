## Review-Settling Contract

`axis-development-supervisor-review` persists schema-versioned review evidence,
polls GitHub within explicit count and time bounds, records inline findings and
checks, requires finding dispositions, blocks unresolved critical/high findings,
requires reviewed-SHA freshness, and runs an independent GPT-5.4 review when
requested. A head SHA change invalidates the independent review and triggers a
new review when `--run-independent-review` is set. GitHub or model unavailability
and polling timeout are fail-closed states. Greptile comments remain evidence;
Greptile approval is not a gate.

The live collector was exercised against #655 and reproduced its exact P1
finding, reviewed SHA, reviewer state, and historical check failures.
