# Supervisor Skill Documentation

The deployed `axis-development-supervisor` skill is stable operating procedure,
not roadmap content. It identifies authoritative sources, execution phases,
authority boundaries, queue invariants, lease requirements, integration gates,
failure behavior, and local audit output.

Volatile work items, branches, MRs, pipelines, SHAs, inventory, and assignments
are injected by preflight or read from live sources. Do not add them to the skill.

Skill changes require a home-flake branch, tests, review, CI, and activation.
Scheduled sessions may not edit the skill, controls, credentials, cron jobs,
repository allowlist, budgets, or decommission criteria.

The skill never grants authority. It constrains execution under authority proven
by GitLab/Contracts/PlanningRecords and enforced by deterministic preflight.
